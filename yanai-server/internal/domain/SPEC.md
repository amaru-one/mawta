## Purpose
Mirrors the schema's text+CHECK "enums" as Go constants so kinds/statuses are never raw string literals in Go code. The mirror covers the tables Go actually reads or writes, not the whole schema.

## Contents
- `consts.go` — constant blocks for session status, score status, scale kinds (`ScaleOrdinal`…), computed-grade scope (`ScopeTermPartial`…) and trend (`TrendUp`/`TrendDown`/`TrendFlat`), voice-note status, the single job kind (`JobKindGradeRecompute`), and the MINEDU vocabulary: conclusión descriptiva requirement + status, and the nivel de logro codes (`LevelC`…`LevelAD`). Every block here has at least one Go call site that passes the value as a query parameter — see Conventions.

## Inputs / Outputs
No dependencies; imported by `repo`, `httpapi`, and `worker`.

## Conventions & Constraints
- Values must exactly match the CHECK constraints in `migrations/` — adding an enum value is a paired change (migration + here; cascade).
- The mirror is not exhaustive by design, and for a structural reason: a value embedded directly in the text of a SQL string (`where status in ('present','late')`) can never be substituted by a Go constant, so a block whose every use is like that is dead on arrival. A block whose subsystem has no Go code left goes the same way. Either is deleted rather than kept as a spelling nobody can reach; re-add it alongside the code that needs it. A block with even one live call site stays whole, including siblings with no reference yet — that is the mirror doing its job.
- Constants only; no logic in this package.

## Change Log
- 2026-09-04: Added `ValueScale*` (`numeric`, `ordinal`, `none`) for `assessments.value_scale` (`migrations/00008`). It is deliberately a separate vocabulary from the `Scale*` block above: that one describes a scale the school configured, this one describes what a single piece of work carries. Both have real Go call sites — `httpapi.handleCreateAssessment` branches on the value scale — so the block earns its place under the rule below. Cascade: `internal/httpapi`.
- 2026-08-29: Second purge pass. Deleted 13 more blocks with zero Go call sites: attendance status, attendance/score `source`, assessment status, `absent_counts_as`, `rounding_mode`, `aggregation`, notification kind/source/severity, job status, memberships/roles, term status, and competency kind. Every one of these was dead for the same structural reason, not just for want of a subsystem: the repo layer writes these values as literals inside SQL query text (`internal/repo/attendance.go`'s `'bulk'`, `internal/repo/classes.go`'s `status in ('present','late')`, `internal/worker/worker.go`'s job-status `in (...)`), and a Go constant can never be substituted into an embedded query string — so the package's own stated goal ("so call sites don't hand-roll the literals") was unreachable for these from the start. Five groups with a live sibling were kept whole (`class_sessions.status`, `scores.status`, `grade_scales.kind`, `computed_grades.scope`, `voice_notes.status`) per the Conventions rule below, which is now spelled out precisely. The Contents line and package doc comment were rewritten to describe the actual criterion. This also fixed a mistake made mid-edit: the first pass at this deletion took the five partial groups with it too, caught by re-grepping before commit. Cascade: none — nothing outside this package referenced any of the deleted names.
- 2026-08-29: Deleted six blocks whose subsystem has no Go code: `scores.attempt_kind`, `grading_scheme_versions.retake_policy`, `note_summaries.status` (the summary route was removed), `voice_notes.transcription_status` (the transcript route was removed), and both `year_final_situations` blocks — PRO/PER/RR and its stage, kept since 2026-08-27 on the argument that the siglas are normative even without code. They still are, and the tables still spell them; the argument for a Go constant nobody can reach was weaker than the cost of a mirror that drifts. Whoever restores year-end close re-adds them with the code. The Purpose and a new convention now say the mirror tracks the Go code, not the whole schema. Cascade: `internal/repo`, `internal/httpapi`.
- 2026-08-27: Removed `JobKindTermFailureRisk`, `JobKindPromotionProjection` and the `risk_flags.status` block — `00003` dropped the risk tables and the handlers that wrote them. The severity block stays (notifications still use it) but its comment no longer claims `risk_rules`/`risk_flags` as sources. The PRO/PER/RR constants are kept: the siglas are normative (RVM 094-2020 5.1.3) even though the code that computed them was cut, and `year_final_situations` still spells them.
- 2026-08-26: Added the constants for migration 00018 (competency kinds, PRO/PER/RR, conclusion requirements, AD/A/B/C codes) and the `risk.promotion_projection` job kind. The level codes live here only as spellings — their *ordering* and every rule that read it belonged to `internal/promotion`, which was removed on 2026-08-27; nothing currently compares them, and nothing should compare them as numbers.
- 2026-08-25: Job kinds reduced to `JobKindGradeRecompute` + new `JobKindTermFailureRisk`; removed `JobKindRiskDetect`, `JobKindNotificationSweep`, `JobKindRetentionSweep`, `JobKindNoteSummaryGenerate` with their handlers. Note the summary/voice-note *status* constants stay — those tables and their columns are untouched.
- 2026-08-24: Initial spec created retroactively, describing current contents.
