## Purpose
The wire layer: the REST client, DTO types matching the server's JSON exactly, and the mappers that convert DTOs into the app's view models.

## Contents
- `client.ts` — the fetch wrapper. Exports `ApiError` (carrying `status`, `code`, `message` and an optional `hint`), `apiGet`, `apiSend` (`POST`/`PUT`, serialising a body only when one is passed), `apiUpload` (multipart, with no `Content-Type` so the browser sets the boundary), `fetchAudioBlob(voiceNoteId)` (a raw fetch of `/voice-notes/{id}/audio`), `list(v)` (`v ?? []`, since empty Go slices serialize as `null`), and `setUnauthorizedHandler(fn)`. `API_BASE` is module-private, read from `PUBLIC_API_BASE_URL`, empty for same origin; every path is prefixed `${API_BASE}/api/v1`. Every request carries `credentials: 'include'` so the `yanai_session` cookie rides along. A 401 fires the unauthorized handler unless the path starts with `/auth/`. A 204 resolves as `undefined` rather than being parsed. A non-`ok` response is turned into an `ApiError` from the body's `{ error: { code, message, hint } }`, falling back to `http_error` for a non-JSON body. The module holds no SvelteKit imports and performs no retries.
- `dto.ts` — the wire types, written as the server serialises them: snake_case fields, UUID strings, RFC3339 timestamps, `YYYY-MM-DD` dates, `null` for an empty list. Shared enums mirror `internal/domain/consts.go`: `SessionStatus`, `ScoreStatus`, `AssessmentKind`, `VoiceNoteStatus`, `NotificationKind`, `Role`, `ValueScale` (`'numeric' | 'ordinal'`), `NivelLogro` (`'AD' | 'A' | 'B' | 'C'`), `CompetencyKind`, `ConclusionRequirement`, `ConclusionStatus`. Payload types cover identity (`MeDto`), home (`HomeDto`, `HomeTodayDto`, `HomeWeekDayDto`, `HomeWeekSessionDto`), the class panel (`ClassDashboardDto`, `SessionSummaryDto`), the lesson roster (`SessionRosterDto`, `RosterEntryDto`, `RosterVoiceNoteDto`), grades (`StudentGradesDto`, `EvaluationDto`, `AttemptDto`, `CriterionRefDto`, `ComputedGradeDto`, `PracticeScoreDto`, `GradingComponentsDto`), the write bodies (`AssessmentCreateDto`, `ScoreCreateDto`, `ScoreCorrectDto`, `PracticeScoreCreateDto`, `CriterionCreateDto`, `AssertCompetencyLevelDto`, `ConclusionCreateDto`), competencias (`CompetencyLevelsDto`, `CompetencyLevelDto`), criterios (`ClassCriteriaDto`, `CompetencyCriteriaDto`, `CriterionDto`), the roster reads (`ClassStudentsDto`, `ClassStudentDto`, `StudentEvidenceDto`), notifications and `ProfileDto`. The file is types only, with no runtime exports.
- `mappers.ts` — `parseDateOnly(d)` (splits `YYYY-MM-DD` into local midnight, avoiding the UTC shift of `new Date(string)`), `formatTimeHHMM(ts)` (local wall clock), `splitDisplayName(name)` (splits at the last space), `toAppNotification(dto)` and `toCompetencyLevel(dto)`. `toAppNotification` strips a leading student name and a trailing `— {class_name}` from the title (the feed renders both separately), maps `kind: 'alert'` to `type: 'risk'` with `aiGenerated: true` and anything else to `'reminder'`, and looks an icon up in a private `CATEGORY_ICONS` map (`attendance_unmarked`, `grades_pending`, `level_drop`, `consecutive_absences`). `toCompetencyLevel` is a field-by-field snake-to-camel conversion, parsing `asserted_at` into a `Date` and passing a null `level` through.
- `endpoints/` — one module per API area (see its SPEC.md).

## Inputs / Outputs
Consumes the Go API under `/api/v1`; produces typed promises for the `lib/` orchestration modules and the route components.

## Conventions & Constraints
- DTOs mirror the server (cascade from `yanai-server/internal/httpapi`). A field the server still sends but no screen reads is left off the DTO, so `dto.ts` types the part of the wire contract this app uses rather than the full JSON — the Go response struct is the full picture. `SessionRosterDto` omits `attendance_status`, `section_average_code`, `attendance_marked` and `attendance_total`; `HomeTodayDto` omits `icon_key` and `is_tutoria`.
- `CompetencyLevelDto.level` is `null` when the competencia was not developed in the period. Screens render that as blank or a dash.
- `ValueScale` distinguishes a numeric mark (`max_score` is non-null) from a letter on one piece of work (`ordinal`). A letter on a piece of evidencia and a nivel de logro are separate values, and nothing converts between them.
- `CriterionDto` and `CriterionRefDto` carry `criterion_id`, an optional `code` and a `description`. The one level type the app writes is `AssertCompetencyLevelDto`.
- `mappers.ts` converts notifications and competency levels. The session roster is converted by private helpers inside `lib/lesson.ts`; home, the class dashboard, grades, criterios and the profile are consumed as DTOs by their screens, which reuse `parseDateOnly` and `formatTimeHHMM` for dates.
