## Purpose
Reusable Svelte components shared across the app's screens. State and API calls live in `lib/*.ts` modules or in the owning route; these render props and call back.

## Contents
- `Icon.svelte` — `name: IconName`, `size = 16`. Renders `<svg class="ic" aria-hidden><use href="#i-{name}" /></svg>`, with `size` applied as `font-size` since `.ic` is `1em` square.
- `IconSprite.svelte` — no props. One hidden `<svg>` holding 24 `<symbol>` definitions on a `0 0 24 24` viewBox, id-prefixed `i-`. Mounted once, from `routes/+layout.svelte`. The ids match `ICON_NAMES` in `lib/icons.ts`.
- `TopBar.svelte` — `back?`, `useHistory = false`, `title?`, `variant: 'default' | 'home' = 'default'`, `showBell = true`, `recording = false`. A 64px band (`.topbar`) closed by the `--hair` rule, with 40px round targets. Renders, in order: a back arrow when `back` is set; either a plain title or the teacher identity block (avatar initials in `--aurora-deep`, `shortName` in `--text-secondary`, school) linking to `/profile`; a home shortcut when `!recording && variant !== 'home'`; then either a blinking accent dot with a mono `REC` label when `recording`, or the bell linking to `/notifications` with an unread dot when `showBell`; and on the `home` variant a `/profile` shortcut carrying the `logout` icon. `onBack` taps haptically, then lets the `href` navigate when `useHistory` is off, `$canGoBack` is false, or the click is modified (meta/ctrl/shift/alt); otherwise it prevents the default and calls `history.back()`. Reads `canGoBack`, `teacher` and `unreadNotificationCount` from `lib/stores.ts`.
- `Toast.svelte` — no props; driven by the `toast` store. A fixed `role="status"` bar keyed on the toast id so a replacement re-runs its fade, carrying the message and, when `undoLabel` is set, an undo button that dismisses first and then calls `onUndo`.
- `ConfirmDialog.svelte` — `title`, `text`, `confirmLabel`, `onconfirm`, `oncancel`. A fixed `role="alertdialog"` with a `scale` transition, a backdrop button and two actions, the confirm one in `--fill-danger`. Escape calls `oncancel`. An `$effect` appends the root node to `document.body` on mount and removes it on unmount, so its `z-index: 2000` is compared at page level rather than inside a caller's stacking context. The `aria-labelledby` id is randomised per instance.
- `AddPracticeScoreDialog.svelte` — `onsubmit(data: PracticeScoreCreateDto)`, `oncancel`. A `role="dialog"` form for a nota personal: título, a tipo `<select>` over the nine `AssessmentKind` values with Spanish labels, nota / sobre number inputs, and an optional internal note. `canSubmit` requires a non-blank title, a finite nota and a positive sobre. Submitting emits the snake_case DTO with a trimmed title and a `null` note when blank. Escape cancels. It renders where it is mounted rather than porting to the body.
- `LevelBadge.svelte` — `tier: Tier`, `size = 22`. One `.lvl` disc sized inline, with its fill and foreground read from two local maps: AD `--fill-accent`, A `--fill-success`, B `--fill-warning`, C `--fill-tier-c` with a `--border-strong` outline.
- `LevelPicker.svelte` — `level: Tier | null`, `disabled = false`, `size = 32`, `onselect(level)`. Four `LevelBadge`s in a row as buttons, the chosen one carrying a 2px `--fill-primary` outline and `aria-pressed`. Used by `CompetencyCard`.
- `LevelScale.svelte` — `level: Tier | null`, `disabled = false`, `onselect(level)`. A `role="radiogroup"` of four bare letters on a bottom hairline, the chosen one underlined and in `--aurora-deep`. Records the value of one piece of evidencia whose `value_scale` is `ordinal`. Taps haptically before calling back.
- `LevelSelector.svelte` — `level: Tier | null`, `disabled = false`, `onselect(level)`. Four 62px cells inside a 1px `--border-strong` box, `role="radiogroup"`, each carrying a letter and its MINEDU label (AD Destacado, A Esperado, B En proceso, C En inicio). The chosen cell takes `--gradient-action`. Records the nivel de logro of a competencia. Taps haptically before calling back.
- `CompetencyIndex.svelte` — `items: CompetencyIndexItem[]`, `selectedId`, `onselect(id)`. A row of buttons scoping a whole screen to one competencia, with a vertical hairline inserted before the first `transversal` item. Three states: faint by default, `--text-secondary` when `item.hasLevel`, and `--aurora-deep` over a 2px underline with `aria-current` when selected. Transversales take a smaller mono label. What `hasLevel` means is set by the caller and differs per screen.
- `ScoreRuler.svelte` — `value: number | null`, `max = 20`, `disabled = false`, `onselect(value)`. A 0..`max` ruler with a fixed 66px readout (`–` when the value is null): `max + 1` equal columns, every fifth bar longer, labels at `0`, `max / 2` and `max`, the chosen column drawn as a bar with a dot. `role="slider"` with the matching `aria-value*`. The track captures the pointer and reads the value from the column under the finger, tapping haptically on each change; `onselect` fires on `pointerup` or `pointercancel`, once, when the committed value differs from `value`. Arrow keys step by one. The track carries `touch-action: none`.
- `CompetencyCard.svelte` — `competency: CompetencyLevel`, `criteria: CriterionDto[] = []`, `onLevelChange(competencyId, level)`, `onSaveConclusion(competencyId, body, includesRecommendations, status)`. An accordion card whose header shows the competencia's name, `No desarrollada este periodo` when `level` is null, a red dot when a conclusión is required and not yet final, and either a `LevelBadge` or an em dash. Expanded, it lists that competencia's criterios as read-only text, then a `LevelPicker` under a note that the level is not computed, then the conclusión descriptiva form (textarea, an `incluye recomendaciones` checkbox, `Guardar borrador` and `Guardar final`) or a dashed button that reveals it. The required-conclusion label is chosen from `conclusionRequirement`. `bodyDraft` is seeded with `untrack` so a parent patch does not overwrite in-progress typing; `Guardar final` stays disabled until the checkbox is ticked.
- `VoiceNotePlayer.svelte` — `note: Note`, `ondelete(note)`. A row playing one stored voice note through Web Audio: `noteAudio(note)` fetches the blob on demand, `decodeBlob` turns it into an `AudioBuffer`, and a `BufferSource` plays from the paused offset while a 100ms interval advances the position readout. Its controls are play/pause and delete, the latter opening a `ConfirmDialog`. The transcript renders beside the duration when present. The interval and any live source are stopped on destroy.
- `RecordBubble.svelte` — `armed`, `onrecorded(blob, durationSec)`, plus `phase` and `elapsedSec` as `$bindable` props the component writes outward. A 232px orb inside a 360×360 stage: four blurred `--aurora-*` lights under one `backdrop-filter` glass surface, an ambient glow, ripples while recording, and a progress arc at `r=132` where one full turn is `MAX_RECORD_SEC`. It owns the press-and-hold machine over `lib/recorder.ts`: a press begins at `pointerdown` (pointer captured), promotes to `recording` after `COMMIT_MS` (400ms) with a start haptic and a 100ms elapsed timer, auto-stops at the cap, and on release emits the blob when the hold passed `COMMIT_MS` or cancels the capture when it did not. Space and Enter drive the same machine. The module script exports `type RecordPhase = 'idle' | 'pressing' | 'recording'`. Spin is changed through `Animation.updatePlaybackRate` (rate 8 while recording, 1 otherwise) rather than by swapping `animation-duration`. SVG filter and gradient ids are namespaced with `$props.id()`. The owning screen sets `--bubble-anchor` and `--bubble-scale` on the stage.

## Inputs / Outputs
Props in, callbacks out, from route pages and `lib/` modules. The only endpoint call is the audio fetch `VoiceNotePlayer` reaches through `lib/lesson.ts`'s `noteAudio`.

## Conventions & Constraints
- Svelte 5 runes throughout: `$props()` against a local `Props` interface, `$state`, `$derived`, `$effect`. Callbacks are plain `onX` function props. `RecordBubble` is the only component using `$bindable`, and no component declares snippets or children.
- Component-scoped `<style>` blocks reading tokens from `src/app.css`. UI copy is Spanish.
- `RecordBubble` is the one component holding its own machine, because `setPointerCapture` has to be called on the element that received the `pointerdown`.
- Selection is painted in aurora and the record in ink: the competency index's current item, `ScoreRuler`'s thumb, `LevelScale`'s underlined letter and `LevelSelector`'s chosen cell take `--aurora-deep` or `--gradient-action`, while a `LevelBadge` and a saved mark take the ink ladder.
- `CompetencyIndex`, `ScoreRuler` and `LevelScale` are line controls with no enclosure; `LevelSelector` is the one boxed control.
- No component computes, suggests or pre-selects a level, and none takes a level for a criterio — criterios render as text.
- Animation respects `prefers-reduced-motion`: CSS animations are dropped by a media query, and SMIL `<animate>` children are left unrendered since a media query cannot switch them off. The recording progress arc is not animation-gated.
