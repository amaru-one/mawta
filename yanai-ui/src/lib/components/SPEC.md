## Purpose
Reusable presentational Svelte components shared across the app's screens. State and API calls stay in `lib/*.ts` modules or the owning route; these render props and emit events.

## Contents
- `TopBar.svelte` — screen header with back navigation. `back` is the destination href; adding `useHistory` makes the arrow return to the previous screen instead, falling back to `back` when there is no in-app history (cold load, refresh, deep link). Modified clicks are never hijacked, so the fallback stays openable in a new tab. `recording` swaps the bell for a blinking accent dot + mono `REC`, so the lesson screen does not have to position anything over another component's box. `Toast.svelte` — global toast (with undo) bound to `lib/toast.ts`.
- `Icon.svelte` / `IconSprite.svelte` — SVG sprite + `<Icon name>` resolver; names typed by `lib/icons.ts` (keep in sync).
- `RecordBubble.svelte` — the lesson screen's whole recording control: an SVG bubble (a `circle r=88` under an `feTurbulence` + `feDisplacementMap` filter, filled by a corner-to-corner gradient) that owns the press-and-hold state machine over `lib/recorder.ts`, plus the recording ripples and the crisp unfiltered progress arc at `r=106` where one full turn is `MAX_RECORD_SEC`. Takes `armed` and `onrecorded`; binds `phase` and `elapsedSec` **out** so the owning screen renders the hint, the countdown and the topbar marker in their own pinned slots.
- `VoiceNotePlayer.svelte` — playback of stored voice notes via `fetchAudioBlob`, with save and delete.
- `LevelBadge.svelte` — MINEDU tier badge (AD/A/B/C via `lib/grades.ts`), used by `LevelPicker`, `CriterionTimeline`, `CompetencyCard` and the lesson screen's section average.
- `LevelPicker.svelte` — four `LevelBadge`s in a row, tappable, for recording a nivel de logro; takes a `size` so it can render small inside an evidence row and full-size for a competencia. It offers no suggestion and never auto-selects. `CriterionTimeline.svelte` — **read-only**: one criterio's text plus its row across the period's evidence (a badge + date + title per cell, scrolling inside itself), and the legacy period-grain level labelled as an earlier record where one exists. `EvidenceCriteriaPickers.svelte` — the criterios one piece of evidencia declares, each with its own `LevelPicker`; this is the only place a criterio level is recorded, and it always knows which evidencia it belongs to. `CompetencyCard.svelte` — accordion card wrapping the competencia's criterios (each a `CriterionTimeline`), then the competency-level `LevelPicker`, then the conclusión descriptiva form (textarea, "incluye recomendaciones" checkbox, draft/final actions); used by the grades screen's competencias section.
- `AddEvidenceDialog.svelte` — dialog for filing one piece of _evidencia_ (título, tipo, componente, sobre, entrega, "cuenta para el promedio interno", and checkboxes for the criterios it evidences). `usesInternalGrading` false hides both the "sobre" field and the internal-average checkbox — a school with no numeric system has no average for evidence to count towards. Takes `scope`: `'student'` (the grades screen — the caller adds the `student_id`) or `'class'` (the class dashboard). The scope is a fixed prop shown as a caption, never a control — which screen you are on is already the answer.
- `AddPracticeScoreDialog.svelte` — dialog for adding unofficial practice scores (notas personales), which are not evidencia and never reach the record. `ConfirmDialog.svelte` — generic confirm modal.

## Inputs / Outputs
Props/events from route pages and `lib/` modules; no direct endpoint calls except audio fetch in `VoiceNotePlayer`.

## Conventions & Constraints
- Svelte 5 syntax; component-scoped styles using tokens from `src/app.css`.
- UI copy is Spanish.
- **A criterio is never graded on its own.** `CriterionTimeline` deliberately has no `LevelPicker`; levels are recorded in `EvidenceCriteriaPickers`, inside the evidencia they were read from (RVM 094-2020, 5.1.1.3 p.3 values evidence _through_ the criterio). Putting a picker back on the criterio row would restore exactly the inversion this design removed.
- **Nothing on the lesson screen carries achievement data.** A nivel de logro is a judgement over a period's evidence (RVM 094-2020, 5.1.1.3 p.2-3), and putting the current one — or a trend arrow off the previous one — beside a name being recorded against invites the second to colour the first. Levels are read and written on the student's grades screen, which is where the evidence is. (This rule outlived the roster row it was written for.)
- **`RecordBubble` is the one deliberately stateful component**, as `MicButton` was before it, and it is stateful for a concrete reason: `setPointerCapture` has to be called on the element that received the `pointerdown`, so the press-and-hold machine cannot be hoisted into the owning page without forwarding four pointer events through props.
- **SVG filter and gradient ids are namespaced with `$props.id()`.** `url(#…)` resolves document-globally, so a static id silently breaks the moment a second instance mounts.
- **Anything animated respects `prefers-reduced-motion`, SMIL included.** SMIL cannot be switched off by a media query, so reduced motion is handled by not rendering the `<animate>` children at all. Information-bearing motion — the recording progress arc — stays.
- **Nothing derives a level from another level.** The timeline displays cells; it never aggregates them, and no component computes a competency level from criterio levels or from marks.

Cascade: `lib/lesson.ts`, `lib/types.ts`, `src/app.css`, `routes/class/[courseId]/lesson/[sessionId]/`, `routes/grades/[studentId]/`.
- 2026-08-28: Criterio levels moved into the evidencia. Deleted `CriterionRow.svelte` (criterio text + its own picker) and replaced it with `CriterionTimeline.svelte`, which is read-only and shows the criterio's row across the period's evidence — read left to right, C → B → A → A is a student who learned to justify, which no single value could say. Added `EvidenceCriteriaPickers.svelte`, the new and only capture point, with per-criterio saving state so one slow save does not freeze the row beside it. `CompetencyCard` swapped `onCriterionLevelChange` for `onopenevidence` (a cell opens the work it came from) and its caption now says the level is read from the criterios in time rather than calculated from them. `AddEvidenceDialog` gained `usesInternalGrading` and the "cuenta para el promedio interno" checkbox, defaulting off for per-student evidence — a recovery task that lifted one student's average hands them an opportunity nobody else had. Cascade: `lib/api/`, `routes/grades/[studentId]/`, `routes/class/[courseId]/evidence/[assessmentId]/`.
